# Multi-tenancy example

This folder contains an adaption of the multi-tenancy example from The Kubernetes Book, Edition 2026 - Chapter 8: Hands-on with Gateway API.

This examples uses the imaginary domain "myapp.com". To follow this example you have to add an entry to your /etc/hosts file:
```
cat /etc/hosts

...
127.0.0.1 myapp.com
```
